# Snake Game

## About the Project
Snake Game is a classic desktop game developed using Python and the Pygame library. The player controls a snake using keyboard keys, collects food, and tries to achieve the highest score without hitting the walls or itself.

## Features

- Simple and interactive game interface.
- Keyboard controls for snake movement.
- Food collection and snake growth.
- Score tracking.
- Collision detection.
- Game over when the snake hits a wall or itself.

## Technologies Used

- **Python:** Used to write the game logic.
- **Pygame:** Used to create the game window, graphics, and controls.

## How to Run the Project

1. Clone this repository:
   git clone https://github.com/navneetkaur10-debug/snake-game-python.git

2. Open the project folder in VS Code.

3. Install Pygame:
   pip install pygame
   
4. Run the game:
   python snake.py
